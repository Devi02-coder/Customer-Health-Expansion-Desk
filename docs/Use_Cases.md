# Use Cases - Startup OS

## Use Case 1: Monitoring Customer Health (Vital Signs)
- **Actor**: Customer Success Manager (CSM)
- **Trigger**: CSM logs into the Mission Control Dashboard.
- **Flow**:
  1. System displays the "Vital Signs" widget with real-time health scores.
  2. CSM notices a "Critical" status on Account X.
  3. CSM clicks on Account X to view detailed "Customer 360" data.
  4. System reveals a drop in usage and recent negative support tickets.
  5. AI Agent suggests a "Proactive Outreach" playbook.
  6. CSM approves the playbook; system schedules a meeting and drafts an email.
- **Outcome**: Risk identified and mitigation triggered.

## Use Case 2: Identifying Expansion Opportunities
- **Actor**: Account Executive (AE)
- **Trigger**: Quarterly Business Review (QBR) preparation.
- **Flow**:
  1. AE navigates to the "Growth Engine" module.
  2. System highlights customers with high "Expansion Potential" scores.
  3. AE selects a target customer.
  4. System analyzes usage data and recommends an "Enterprise Plan" upgrade.
  5. AE uses the "Generate Proposal" feature to create a data-driven pitch deck.
- **Outcome**: High-probability upsell opportunity identified and prepped.

## Use Case 3: Real-time AI Analysis (Agent Console)
- **Actor**: Business Analyst
- **Trigger**: Complex query about churn trends.
- **Flow**:
  1. Analyst opens the "Agent Console".
  2. Analyst types: "Analyze churn reasons for the last quarter vs. product updates."
  3. AI Agent queries the database and event logs.
  4. Agent returns a visualized report showing a correlation between a specific bug and churn.
  5. Agent recommends immediate bug fix prioritization.
- **Outcome**: Data-driven insight obtained in seconds without manual SQL queries.

## Use Case 4: System Configuration & RBAC
- **Actor**: System Administrator
- **Trigger**: Onboarding a new team member.
- **Flow**:
  1. Admin goes to "System Config" -> "User Management".
  2. Admin invites a new user and assigns the "Viewer" role.
  3. System restricts the new user's access to "Read-Only" views of specific dashboards.
  4. Admin later promotes the user to "Editor", granting write access.
- **Outcome**: Secure, role-based access management.
