---

// turbo-all
1. Ensure the MySQL server is running.
2. Initialize the database by running `backend/schema.sql`.
3. Open a terminal in the `backend` directory and run:
   ```powershell
   npm install
   node server.js
   ```
4. Open another terminal in the `frontend` directory and run:
   ```powershell
   npm install
   npm run dev
   ```
5. Navigate to the local Vite URL (e.g., http://localhost:5173) in your browser.
